## O que ele faz?

Usa compareTo() em Float para realizar a operação indicada pela API Java.

```java
int resultado = Float.valueOf(1).compareTo(2);
```

## Comportamento

O resultado e os efeitos dependem dos argumentos e do contrato de Float. Verifique o retorno antes de continuar quando a operação puder indicar ausência, falha ou mudança de estado.
