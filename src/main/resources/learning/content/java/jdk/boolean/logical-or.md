## O que ele faz?

Usa logicalOr() em Boolean para realizar a operação indicada pela API Java.

```java
boolean valor = Boolean.logicalOr(true, false);
```

## Comportamento

O resultado e os efeitos dependem dos argumentos e do contrato de Boolean. Verifique o retorno antes de continuar quando a operação puder indicar ausência, falha ou mudança de estado.
