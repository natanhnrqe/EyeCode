## O que ele faz?

Usa toLowerCase() em Character para realizar a operação indicada pela API Java.

```java
char letra = Character.toLowerCase('a');
```

## Comportamento

O resultado e os efeitos dependem dos argumentos e do contrato de Character. Verifique o retorno antes de continuar quando a operação puder indicar ausência, falha ou mudança de estado.
