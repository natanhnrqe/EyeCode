## O que ele faz?

Usa valueOf() em Double para realizar a operação indicada pela API Java.

```java
Double valor = Double.valueOf("42");
```

## Comportamento

O resultado e os efeitos dependem dos argumentos e do contrato de Double. Verifique o retorno antes de continuar quando a operação puder indicar ausência, falha ou mudança de estado.
